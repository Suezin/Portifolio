# Portfólio de Suezin

Este é o meu site de portfólio, feito com HTML e CSS. Aqui eu reúno as minhas habilidades, os meus estudos e os projetos que já desenvolvi.

## Componentes

**Página inicial**
- Uma apresentação sobre mim: quem eu sou, onde moro e o que busco na área de tecnologia.

**Habilidades**
- Java (POO, JDBC), MySQL, HTML, CSS, JS, hardware e sistemas operacionais.

**Estudos**
- Minha formação (técnico em Informática e técnico em Administração) e o que estou aprendendo no momento, como estruturas de dados em Java.

**Projetos**
- Todos os projetos que eu faço, mesmo os que ainda não estão polidos ou terminados. Cada um tem uma descrição e um link para o repositório.

## Por que eu fiz isso?

Para ter um lugar só meu, onde qualquer pessoa pode conhecer meu trabalho. Também porque a melhor forma de aprender é fazendo, e um site pessoal é um ótimo projeto para praticar e mostrar minha evolução.

## Tecnologias

- **HTML:** estrutura das páginas
- **CSS:** estilização e layout
- **JavaScript:** interatividade 

## Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Entre na pasta do projeto:

```bash
cd seu-repositorio
```

3. Abra o arquivo `index.html` no navegador.
